# State history source data

The data embedded in `cross-country-records.html` comes from these CSVs. Rebuild the page from them after each CIF State meet and each Clovis Invitational. Don't hand-edit the data in the page.

| File | What it holds |
| --- | --- |
| `mv_cif_state_xc_individuals_1987_2025.csv` | Every Monte Vista individual run at CIF State, 1987–2025 |
| `mv_woodward_park_all_marks.csv` | Every Monte Vista 5K mark at Woodward Park (CIF State, Clovis, Rough Rider, NXR) |

The script that turns these CSVs into the page's `DATA` objects isn't in the repo yet.

These are public race results. GitHub Pages serves this folder, so they are publicly downloadable.
